# 🔧 לוח סטטוס רכבים במוסך — בזמן אמת

אפליקציה פשוטה שמראה לכל העובדים, לנותני השירות ולפקידות **איפה כל רכב נמצא עכשיו**:
קבלה ← אבחון/דיאגנוסטיקה ← ממתין לאישור לקוח / לחלקים ← מכונאות / חשמל / פחחות ← בדיקה ← מוכן לאיסוף ← נמסר.

כל עדכון (מהטלפון של המכונאי או מהמחשב במשרד) מופיע **מיד** אצל כולם, בלי לרענן את הדף.

## מה יש בפנים
- **לוח לפי שלבים** — כל רכב בכרטיס עם מספר רישוי, דגם, סוג (כבאית, משאית…), מה עושים עכשיו ("החלפת ברקסים"), מכונאי אחראי, לקוח וצפי סיום.
- **כמה זמן הרכב בשלב הנוכחי** — מתעדכן לבד.
- **סימון דחוף** (למשל כבאית שצריכה לחזור לשירות) — דחופים מוצגים ראשונים וממוסגרים באדום.
- **התראת איחור** כשעובר צפי הסיום.
- **היסטוריה מלאה לכל רכב** — מי העביר לאיזה שלב ומתי.
- **מסך טלוויזיה** (`/tv`) — תצוגה גדולה לקריאה בלבד, לתלות במשרד או בקבלת לקוחות.
- **חיפוש** לפי מספר רישוי, דגם, לקוח או מכונאי.
- **קוד עריכה** — כולם יכולים לצפות, רק מי שיודע את הקוד יכול לשנות.
- עובד בטלפון, בטאבלט ובמחשב. בלי התקנות, בלי חשבונות, בלי ענן.

## התקנה (פעם אחת, על מחשב אחד במוסך)
1. מתקינים Node.js (גרסה 18 ומעלה) מ־https://nodejs.org
2. מעתיקים את התיקייה `garage` למחשב.
3. פותחים חלון פקודה (cmd) בתוך התיקייה ומריצים:

   ```
   set EDIT_PIN=1234
   node server.js
   ```
   (במק/לינוקס: `EDIT_PIN=1234 node server.js`. כדאי לבחור קוד אחר במקום 1234.)

4. בחלון יופיעו כתובות, למשל:
   ```
   ברשת המוסך: http://192.168.1.20:3000
   ```
   את הכתובת הזו פותחים **בכל טלפון/מחשב שמחובר ל־Wi‑Fi של המוסך**.
   למסך הטלוויזיה: `http://192.168.1.20:3000/tv`

> טיפ: בטלפון אפשר ללחוץ "הוסף למסך הבית" כדי שזה ייראה כמו אפליקציה.

## שימוש יומיומי
- **רכב נכנס** ← "+ רכב חדש", ממלאים מספר רישוי, דגם ומה צריך לעשות.
- **הרכב עובר שלב** ← לוחצים על הכרטיס ← לוחצים על השלב החדש (למשל "מכונאות"), ומעדכנים את "מה עושים עכשיו".
- **הרכב יצא** ← מעבירים ל"נמסר ללקוח". הוא נעלם מהלוח ונשאר ברשימת "נמסרו".

בפעם הראשונה שעורכים, האפליקציה שואלת את השם (בשביל ההיסטוריה) ואת קוד העריכה.

## הגדרות
| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `PORT` | `3000` | הפורט שהשרת מאזין לו |
| `EDIT_PIN` | ריק | קוד לעריכה. אם ריק, כל מי שברשת יכול לערוך |
| `DATA_FILE` | `data.json` | איפה נשמרים הנתונים |

את שמות השלבים והצבעים אפשר לשנות במערך `STAGES` בראש הקובץ `server.js`.

## גיבוי
כל המידע נשמר בקובץ אחד: `data.json`. מספיק להעתיק אותו מדי פעם לדיסק־און־קי או לענן.

## גישה מחוץ למוסך (אופציונלי)
כברירת מחדל הלוח זמין רק ברשת של המוסך. אם רוצים לראות אותו גם מהבית או מהשטח,
אפשר להעלות את התיקייה לשירות אחסון כמו Render או Railway (חובה להגדיר `EDIT_PIN`),
או להשתמש ב־Tailscale / Cloudflare Tunnel מהמחשב שבמוסך.
