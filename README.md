# 🔧 לוח סטטוס רכבים במוסך

אפליקציה שמראה לכל העובדים, לנותני השירות ולפקידות **איפה כל רכב נמצא עכשיו**:
קבלה ← אבחון/דיאגנוסטיקה ← ממתין לאישור לקוח / לחלקים ← מכונאות / חשמל / פחחות ← בדיקה ← מוכן לאיסוף ← נמסר.

- עובדת **מכל טלפון ומחשב, מכל מקום**, דרך לינק אחד.
- כל עדכון מופיע **מיד** אצל כולם.
- מסך טלוויזיה למשרד: מוסיפים `?tv` בסוף הלינק.
- כל רכב מקבל היסטוריה מלאה: מי העביר לאיזה שלב ומתי.
- סימון דחוף, צפי סיום והתראת איחור.
- כניסה עם סיסמת מוסך אחת. מי שאין לו את הסיסמה לא רואה כלום.
- חינם: הנתונים נשמרים ב-Firebase של גוגל, והאתר מתארח ב-GitHub Pages.

---

## הקמה (פעם אחת, כ-10 דקות)

### שלב 1: פותחים פרויקט Firebase
1. נכנסים ל-https://console.firebase.google.com עם חשבון גוגל.
2. **Create a project**. שם לדוגמה: `my-garage`. את Google Analytics אפשר לכבות.

### שלב 2: מסד נתונים
1. בתפריט הצד: **Build → Firestore Database → Create database**.
2. מיקום: `me-west1 (Tel Aviv)`.
3. מצב: **Production mode** ← Create.

### שלב 3: חשבון כניסה למוסך
1. **Build → Authentication → Get started**.
2. **Sign-in method → Email/Password → Enable → Save**.
3. בלשונית **Users → Add user**:
   - מייל: למשל `garage@my-garage.com` (לא חייב להיות מייל אמיתי)
   - סיסמה: הסיסמה שכל העובדים יקלידו

### שלב 4: חוקי אבטחה
1. **Firestore Database → Rules**.
2. מוחקים את מה שיש שם ומדביקים את כל התוכן של הקובץ [`firestore.rules`](firestore.rules).
3. מחליפים את המייל שבקובץ במייל משלב 3 ← **Publish**.

### שלב 5: מחברים את האפליקציה
1. ⚙️ **Project settings** ← למטה **Your apps** ← לוחצים על האייקון `</>` (Web).
2. נותנים שם (למשל `garage-board`). **אין צורך** לסמן Firebase Hosting ← Register app.
3. מעתיקים את הקטע `const firebaseConfig = { ... }`.
4. ב-GitHub פותחים את הקובץ [`config.js`](config.js) ← ✏️ עריכה, ומדביקים:
   - את התוכן של firebaseConfig במקום `null`
   - את המייל משלב 3 ב-`GARAGE_LOGIN_EMAIL`
   - Commit changes.

### שלב 6: מקבלים לינק
1. ב-GitHub: **Settings → Pages**.
2. Source: **Deploy from a branch** ← בוחרים את הענף ← תיקייה `/ (root)` ← Save.
3. אחרי דקה-שתיים יופיע הלינק, בערך כך: `https://<שם-המשתמש>.github.io/<שם-המאגר>/`

> אפשר לשנות את שם המאגר (Settings → General → Repository name), למשל ל-`garage`, כדי שהלינק יהיה יותר נוח.

## שליחה לעובדים
שולחים את הלינק בוואטסאפ. כל עובד:
1. פותח את הלינק ומקליד את סיסמת המוסך ואת השם שלו. זה קורה פעם אחת בכל מכשיר.
2. **בטלפון כדאי להוסיף למסך הבית**, וכך זה ייראה כמו אפליקציה:
   - **אייפון (Safari):** כפתור השיתוף ⬆️ ← "הוסף למסך הבית"
   - **אנדרואיד (Chrome):** תפריט ⋮ ← "הוספה למסך הבית" / "התקנת אפליקציה"

**מסך טלוויזיה במשרד:** פותחים בדפדפן של הטלוויזיה או של מחשב שמחובר אליה את הלינק עם `?tv` בסוף, למשל `https://.../garage/?tv`.

## שימוש יומיומי
- **רכב נכנס:** "+ רכב חדש", ממלאים מספר רישוי, דגם ומה צריך לעשות.
- **רכב עובר שלב:** לוחצים על הכרטיס ← לוחצים על השלב החדש. אפשר לעדכן באותו חלון גם את "מה עושים עכשיו".
- **רכב יצא:** "נמסר ללקוח". הוא יורד מהלוח ונשאר ברשימת "נמסרו".

## שאלות נפוצות
- **רוצים להחליף סיסמה?** Firebase → Authentication → Users ← ⋮ ליד החשבון ← Reset password. אחרי ההחלפה כל המכשירים יצטרכו להיכנס מחדש.
- **הנקודה בראש המסך אדומה?** אין אינטרנט. מה שמוצג הוא המידע השמור האחרון, ועדכונים שתעשו יישלחו לבד כשהחיבור יחזור.
- **רוצים לשנות שמות שלבים?** הם מוגדרים ב-`STAGES` בקובץ `index.html`. אין צורך לעדכן את חוקי האבטחה.

# 📦 מחסן החלקים

נמצא באותו אתר, בכתובת שמסתיימת ב־`/warehouse/`, ויש אליו גם כפתור "📦 מחסן" בלוח הרכבים.
הוא משתמש באותו Firebase ובאותה סיסמת מוסך, ולכן אין צורך בהקמה חדשה.

- מודל תלת־ממד של המחסן: מקלידים מק״ט ורואים באיזה מדף, קומה ותא הוא נמצא.
- הוספה, העברת מיקום ועדכון כמות. כל שינוי מופיע מיד אצל כולם, עם השם של מי שעשה אותו.
- ייבוא רשימת מלאי מ־Google Sheets או מאקסל (CSV), וייצוא של כל המלאי לאקסל.

## הפעלה (פעם אחת)
צריך להוסיף למסד הנתונים הרשאה לשתי הרשימות של המחסן:
1. Firebase ← **Firestore Database ← Rules**.
2. מוחקים את מה שיש שם ומדביקים את כל התוכן החדש של [`firestore.rules`](firestore.rules). החוקים של לוח הרכבים נשארים בו כמו שהם.
3. **Publish**.

בלי השלב הזה, מסך המחסן יציג "אין הרשאה לקרוא את המלאי".

## שינוי מבנה המחסן
מספר המדפים בכל צד, הקומות והארונות מוגדרים בראש הקוד ב־`warehouse/index.html`, בבלוק
`Warehouse layout`, למשל `SIDE_ROWS`. הפריטים שכבר הוזנו לא נמחקים כשמשנים את המבנה.
פריט שהמדף שלו כבר לא קיים יופיע ברשימת "פריטים בלי מיקום".
